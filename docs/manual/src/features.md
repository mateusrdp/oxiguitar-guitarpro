# Features and their tests

Everything the Guitar Pro plugins do, and the tests that check it. The test names are the ones `cargo test` prints (a name starting with a package, such as `oxiguitar-gp5-plugin/`, is that plugin's own test); a `stage:` is a step of `scripts/test-all.py`. The script fails when a feature here names no test, or names a test that doesn't exist, so a new feature gets its row and its tests in the same pull request (the [Testing](testing.md) page says how to run them, on your own files too).

The five plugins (`gp3`, `gp4`, `gp5`, `gpx`, `gp`) share the readers and writers of the `oxiguitar-formats` crate. CI also has other programs read what we write (`interop.yml`: alphaTab and MuseScore 4); that needs those programs, so it isn't part of the script.
